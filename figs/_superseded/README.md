# Superseded figures — do not use

**two_ceilings.png** — withdrawn 30 August 2026.

Three faults:

1. It states an economic ceiling of 9 cycles and a physical ceiling of 10.
   Neither is supported by `results/controller_summary.json`, which gives 7 and 8.
2. It asserts that beyond the economic ceiling "acid starts costing more than the
   water saved", i.e. that the cost curve turns over. On this water it does not:
   `results/v5b_two_ceilings.csv` shows cost falling monotonically from $209.08/h
   at 3 cycles to $191.22/h at 7, the last feasible point.
3. It carries an embedded editorial title, which the current figure style
   forbids because the surrounding document supplies the headline.

It was produced by an early one-off script that is no longer in `FIGURES`, so it
was never regenerated when the results changed. The replacement is
`gypsum_wall.png`, which is generated by `fig_gypsum_wall` in `make_figures.py`
and therefore cannot drift from the results.

`docs/linkedin_outreach.md` still references this file. That document is
superseded by `docs/outreach_saudi.md`.
